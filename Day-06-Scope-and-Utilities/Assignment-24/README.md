
# Assignment 24 – JavaScript Practical

## Objective
To test reusable JavaScript utility functions using different test cases.

## Functions Tested
1. Name Validation
2. Age Validation
3. Email Validation
4. Settings Merge
5. Total Calculation

## Testing
All functions were tested with valid and invalid inputs.

The functions returned the expected outputs for the test cases.

## Reflection
Through this practical, I learned how to create reusable functions, use guard clauses, merge objects, calculate totals using loops, and test functions with different inputs.
