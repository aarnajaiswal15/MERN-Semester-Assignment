
# Interactive Profile - Event Map

## Events Used

| Event | Element | Action |
|---|---|---|
| click | Activate Profile button | Activates or deactivates the profile |
| click | Show Details button | Displays student details in an alert box |

## JavaScript Methods Used

1. addEventListener()
2. classList.toggle()
3. classList.contains()
4. textContent
5. setAttribute()

## Expected Behaviour

- Clicking Activate Profile changes the profile appearance.
- The status message changes to Profile is active.
- The button text changes to Deactivate Profile.
- Clicking it again restores the inactive state.
- Clicking Show Details displays student information.
